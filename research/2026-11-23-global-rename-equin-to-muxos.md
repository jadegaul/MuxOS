# Rename the product from `equin` to `MuxOS` (global)

2026-11-23. Requested by the user: replace all references to `equin` in the repo with
`MuxOS`, **except `README.md`** (the upstream equin readme; its SVG assets
`docs/readme/*.svg` stay with it).

## Context

The user's canonical repo is now `github.com/jadegaul/MuxOS` (both remotes point at it;
first release `v2026.11.23` cut 2026-11-23 on `be1b8f55de`). The product's own name is
still `equin` everywhere: the `PRODUCT_NAME` constant, the `./equin` CLI, the `~/.equin`
data root, the `equin.localhost` host label, the `EQUIN_*` env prefix, the `@equin/*`
package scope, service labels, UI copy and docs.

**This product has been renamed once before** — Singularity → equin (2026-10) — with
exactly the machinery this plan replays: the one-constant flip, the old name demoted to
`LEGACY_PRODUCT_NAMES`, the kept identifiers declared in `LEGACY_IDS` (with `mirrors` for
files that cannot import), the host-alias table, chained CLI shims, and
`./equin data-dir migrate`. Precedent plans:
`2026-10-25-global-equin-internal-identifiers.md`, `2026-10-28-global-equin-github-repo-rename.md`,
`2026-10-26-global-equin-data-dir-migration{,-v2}.md`, `2026-10-25-global-equin-env-vars.md`.

Scale (census 2026-11-23, case-insensitive, excluding `node_modules`/`.git`): ~9,241 files
/ ~25,312 lines total — of which autogen ~3,000 L (regenerated by the build), research/
8,536 L (history, exempt), 1,955 `@equin/*` package names (zero import sites — pure
churn), UI copy 438 L/~225 files, hand-written docs ~1,500 L, install.sh 206 L, gateway
Go 226 L, the rest mirrors/tests/fixtures.

## Design

### 1. Central flip — the `product-name` leaf (`plugins/framework/plugins/product-name/`)

- `core/internal/product-name.ts`: `PRODUCT_NAME = "muxos"`; add
  `PRODUCT_DISPLAY_NAME = "MuxOS"` (display-only — brand spots named above);
  `LEGACY_PRODUCT_NAMES = ["Singularity", "equin"]`.
- `core/internal/source-repo.ts`: `SOURCE_REPO = "jadegaul/MuxOS"` (+ URL).
- `core/internal/legacy-ids.ts` — value rolls, following the "kept while it exists" notes:
  - `dataDirName: ".singularity" → ".equin"` (the pre-migration dir of an install not yet
    moved). Mirrors update to spell the new value: `gateway/dataroot.go`, `install.sh`,
    `doctor.sh`, `declare-data-root.sh`, the sidequests scripts. The `.singularity` literal
    leaves the tree (no machine holds it).
  - `launchdLabel: "dev.singularity.gateway" → "dev.equin.gateway"` (the installed service
    of an install not yet migrated; the gateway login service relabels to
    `dev.muxos.gateway` at migration time). Mirrors: `install.sh`, the gateway-service
    definition.
  - `cliShim: "singularity"` → `cliShims: ["equin", "singularity"]` (a list now — the old
    name has two generations). Consumers: the `cli:legacy-cli-name` lint and the `bin`
    mirror in `plugins/framework/plugins/cli/package.json`.
  - New kept id: `mainHostAlias: "equin"` — the previous generation's public label, still
    dialed by pre-rename `EQUIN_…PARENT_URL` values, bookmarks and transcripts; it resolves
    to the main namespace. Mirror: `gateway/proxy.go`.
- **`product-name:legacy` check redesign** (`check/index.ts`): the word regex
  `(?<![\w-])NAME(?![\w]|-[A-Z])` now also applies to lowercase `equin`. Punctuation is a
  word boundary, so stragglers (`@equin/x`, `.equin`, `equin.localhost` in docs) are
  correctly violations; the kept-id mirror spellings must pass. Rule: **a match is a
  violation unless it sits on a line of a declared mirror carrying that kept-id value**
  (the `LEGACY_ID_NOTES.mirrors` manifest the `legacy-id` check already parses — no
  hand-rolled allowlist). The product-name plugin dir extends its self-exemption to the
  new declaration lines. `research/`, generated artifacts and committed migrations stay
  exempt. Test matrix: `Ask equin for` → fail · `@equin/x` straggler → fail ·
  `hostAliases["equin"]` in `gateway/proxy.go` (mirror) → pass · `~/.equin` in
  `install.sh` (mirror) → pass · `equin.localhost` in a doc example → fail · a comment
  `// the equin era` in a live file → fail.
- `product-name:legacy-id` inherits the new id automatically (it reads `LEGACY_IDS`);
  its mirror-sync twin (`legacy-ids-in-sync`) covers the new mirrors.
- `product-name/CLAUDE.md` + the leaf's description string updated.

### 2. Namespace — labels and the second-gen alias (`plugins/infra/plugins/namespace/core/namespace.ts`)

`NAMESPACE_HOST_LABELS = { [MAIN_WORKTREE_NAME]: PRODUCT_NAME }` flips to `muxos` for free.
The derived inverse `NAMESPACE_HOST_ALIASES` is a one-label-per-namespace function and
cannot express a **second** legacy label, so a declared record is merged in:

```ts
/** Previous-generation public labels, kept answering for the namespaces they served. */
export const LEGACY_HOST_ALIASES: Readonly<Record<string, Namespace>> = {
  equin: MAIN_WORKTREE_NAME,
};
export const NAMESPACE_HOST_ALIASES = { ...derivedInverse, ...LEGACY_HOST_ALIASES };
```

`isNamespaceHostAlias` / `resolveNamespaceAlias` / `namespaceFromHost` inherit it.
`namespace:grammar-in-sync` pins the gateway's `hostAliases` (`gateway/proxy.go`) against
the whole table — the Go mirror gains the `muxos` entry and keeps `equin`.
The `namespace:legacy-host` check (keeps the old main address out of tracked files) must
cover both old spellings (`equin`, `singularity`) — extend its derivation if it tracks
only the own name. Tests: `equin`→`singularity` resolution, `muxos` label, own-name
resolution, and the collision guard refusing a future checkout claiming `equin`.

### 10. Staged data-root cutover (D2)

Post-deploy, `dataRootLayout()` finds a real `~/.equin` and no `~/.muxos` → root is
`~/.equin` in **legacy mode: every component keeps running, zero downtime** (the layout
decides by disk, not by code version — the exact behaviour that made the first
migration safe). Nothing to restart except the usual deploy.
Later, at the user's chosen quiet moment: `./equin data-dir migrate --apply` — refuses
while any op or agent runs; stops the app; renames `~/.equin` → `~/.muxos` (and the
backups dir beside it); rewrites every stored copy of the old path (one rule: a stored
value that STARTS with the old prefix is a path — every database, the files under the
root, links, Claude Code's transcript dirs); never rewrites history (`*.jsonl`, run
transcripts — read by byte offset); drops cache entries holding the old path; keeps the
compat link `~/.equin → ~/.muxos` while `staleCheckouts` is non-empty (any checkout whose
HEAD lacks the renamed code — cleared by rebuilding each of them; the plan names them)
and the leftover scan is empty; relabels the gateway login service
`dev.equin.gateway` → `dev.muxos.gateway`; starts the app. Rollback: the link plus
rename-back. After the migration, restart the manually-run llm-proxy (its pid file and
the accounts file move under the root).

## Risks and mitigations

1. **Env prefix vs the running gateway** — the old gateway binary hands `EQUIN_*` to
   backends it spawns until main's deploy rebuilds it; the deploy restarts everything in
   one shot (brief mixed window = one backend restart). Mitigation: single deploy, verify
   health + one agent spawn after.
2. **Stale tabs across the deploy** — send `X-Equin-*` / `equin-snapshot` to the new
   build: unauthenticated reload, self-healing (D5 chose cutover over retention).
3. **Data-dir migration** — the proven tool (used for Singularity→equin); the staged
   layout option (§10) makes it non-blocking; its `staleCheckouts` gate keeps the compat
   link until every checkout has rebuilt.
4. **Check false positives** — the lowercase mode's mirror-manifest consultation + the
   §1 test matrix; a failing check lists offenders line-by-line, so a wrong exemption is
   loud, not silent.
5. **bun workspace rename** — 1,955 files + lock regen; zero import sites; `bun install`
   + a green build verify before the cutover deploy.
6. **Go module rename** — `go.mod` + internal import paths + `go build` before push.
7. **CI gate** — `installer-release.yml` flips in the same commit (D7).
8. **The website `readme` sub-plugin** renders the untouched upstream `README.md` —
   accepted (the exclusion travels with the file).
9. **The root `.mcp.json` fallback URL** — verify the no-hand-built-namespace-url
   treatment of the fallback line at implementation (it currently spells
   `equin.localhost`); the flip must satisfy whatever exempts it today.
